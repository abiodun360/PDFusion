Why I built PDFusion

I needed to merge PDFs regularly and found existing tools either cost money, had file limits, or uploaded files to unknown servers. So I built my own — and made it free for everyone.

🔒

Privacy first

PDFusion processes everything in memory. Your files are never written to disk and never stored on any server. Once your download starts, the data is gone.

🌍

Open source

The full source code is available on GitHub. Feel free to use it, fork it, or contribute — that's the whole point of sharing it.
